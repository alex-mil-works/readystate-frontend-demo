# Замыкание — функция + лексическое окружение

Когда функция создаётся, она захватывает **ссылку** на scope, в котором была определена. Это и есть _closure_ — замыкание.

```js
function makeCounter() {
  let count = 0;
  return function increment() {
    count++;
    return count;
  };
}

const counter = makeCounter();
counter(); // 1
counter(); // 2
counter(); // 3
```

`increment` продолжает видеть `count`, хотя `makeCounter` уже завершился. Переменная не копируется — замыкание хранит **ссылку** на тот же binding.

## Что именно захватывается

Замыкание не копирует значение на момент создания функции. Оно удерживает **живую ссылку** на переменную:

```js
function makeGreeter() {
  let name = 'Alice';

  const greet = () => `Hi, ${name}`;
  name = 'Bob'; // мутация до вызова greet

  return greet;
}
makeGreeter()(); // 'Hi, Bob' — захвачена ссылка, не значение
```

Это ключевой момент: если внешняя переменная меняется после создания замыкания, внутренняя функция увидит **новое** значение.

## Почему это важно для React

В React каждый render создаёт новое замыкание: обработчики и эффекты захватывают props и state конкретного рендера. Если state обновился, а handler помнит старый — это _stale closure_. Понимание механизма замыканий — основа для работы с hooks.
