# Паттерны замыканий

## Фабрика функций

Замыкания позволяют создавать «настроенные» функции:

```js
function multiply(factor) {
  return (n) => n * factor;
}
const double = multiply(2);
const triple = multiply(3);
double(5); // 10
triple(5); // 15
```

Каждый вызов `multiply` создаёт **новый scope** с собственным `factor`.

## Приватное состояние (module pattern)

До ES Modules замыкания были основным способом скрывать переменные:

```js
const counter = (() => {
  let count = 0;
  return {
    inc: () => ++count,
    get: () => count,
  };
})();

counter.inc(); // 1
counter.get(); // 1
// count недоступен снаружи
```

## Память и утечки

Замыкание удерживает весь scope chain внешней функции. Если внешняя функция создала большой массив, а вы храните замыкание — массив не будет собран GC.

_Коротко:_ замыкание — мощный инструмент, но следите за тем, что оно удерживает. Особенно при подписках, таймерах и обработчиках событий.
