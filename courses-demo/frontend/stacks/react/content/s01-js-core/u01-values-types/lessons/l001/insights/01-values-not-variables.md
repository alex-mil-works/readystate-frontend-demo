# Значение vs переменная

В JavaScript **тип принадлежит значению**, а не имени переменной. Переменная — это привязка (binding) к значению в текущем lexical environment.

```js
let x = 42;
x = 'hello';
```

После второй строки `x` указывает на **другое** значение другого типа. Язык **динамически типизирован**: одна переменная может ссылаться на число, строку, объект — без объявления типа заранее.

Коротко: _тип не у переменной, а у значения; операция проверяется в момент выполнения над конкретным значением_.

## Что хранится в памяти

- **Примитивы** (`number`, `string`, `boolean`, `bigint`, `symbol`, `undefined`, `null`) — обычно копируются по значению при присваивании.
- **Объекты** (включая массивы, функции, plain objects) — переменная хранит **ссылку** на объект в heap; присваивание копирует ссылку, не сам объект.

```js
const a = { n: 1 };
const b = a;
b.n = 2;
console.log(a.n); // 2 — одна и та же ссылка
```
