# Примитивы и объекты в runtime

JavaScript делит значения на два класса:

| Класс    | Примеры                           | Передача при `=` |
| -------- | --------------------------------- | ---------------- |
| Примитив | `42`, `'hi'`, `true`, `undefined` | копия значения   |
| Object   | `{}`, `[]`, `function(){}`        | копия ссылки     |

**Immutable primitives:** строку или число нельзя «изменить на месте» — только создать новое значение. Объект можно мутировать через ссылку.

## Паттерны и ловушки в проде

1. **Props/state** — передача объекта в дочерний компонент не клонирует данные; мутация props — **антипаттерн**.
2. **Сравнение** — два разных объекта с одинаковым содержимым `{a:1}` и `{a:1}` не равны по `===` (разные ссылки). Best practice: сравнивать по identity или нормализовать данные явно.
3. **Coercion** — при операциях движок может временно оборачивать примитив в объект (boxed), но это деталь реализации, не «настоящий object» в модели языка.

Короткая формула: _примитив — атомарное значение; object — контейнер по ссылке_.
