# if/switch/loops в QA

В Java управление потоком — это не только «синтаксис», а способ сделать test helpers:

- предсказуемыми (одинаковый результат при тех же inputs)
- читаемыми (ранний `return` вместо глубокой вложенности)
- дебажными (простые ветвления, понятные при падении)

## Best practice

- используйте `if/else` для простых развилок
- используйте `switch` для выбора по одному значению (enum/строка)
- избегайте больших `switch` без `default` (иначе пропуски веток)
